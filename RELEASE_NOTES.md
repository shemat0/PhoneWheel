# PhoneWheel 1.8

- Добавлен отдельный режим «Стик»: крупное плавное руление слева и восемь настраиваемых Xbox-кнопок справа.
- Стик возвращается в центр при отпускании, отмене касания и открытии меню; небольшая мёртвая зона убирает дрожание пальца.
- Гироскоп и стрелки сохранены, настройки трёх режимов независимы.

Установите APK и включите МЕНЮ → Режим управления → Стик. Приёмник Windows в этом выпуске — проверенная совместимая версия 1.7; он прикреплён к релизу вместе с новым APK. Драйвер менять не требуется.

Проверены сборка, подписи APK, 36 тестов Python и 1146 проверок Java. Работа нового интерфейса на физическом телефоне и фактическая задержка Bluetooth не проверялись.
